# Synthetic fixtures

Everything in this folder is fictional and generated by `tools/build_fixtures.py`.
Sample hashes are digests of labels, not of files. No real tool output, sample or payload is stored here.

`attack_map.csv` is a fictional mapping table (T0001 is a made-up revoked ID that maps to T1027);
it is **not** the official ATT&CK export. Edit the generator, not the files, then rerun it so
the hashes in `specs.json` stay correct.
